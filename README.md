# Метафорические карты — пилотный проект

## Структура проекта

- `app/` — страницы сайта (Next.js)
  - `page.js` — главная страница
  - `catalog/` — каталог готовых карт (наполняется на Этапе 2)
  - `generate/` — генерация своей карты через нейросеть (Этап 3)
  - `admin/` — личный кабинет для управления картами (Этап 2)
  - `api/` — серверные обработчики (для генерации, тестовой кнопки оплаты и т.д.)
- `components/` — переиспользуемые UI-блоки (карточка, кнопка и т.п.)
- `public/cards/` — папка для изображений карт

## Выбор платформы и хостинга

- **Платформа:** Next.js (React) — быстрая сборка MVP, легко расширяется под будущие
  этапы без переписывания с нуля.
- **Хостинг для пилота:** Render.com (бесплатный тариф, без привязки карты, деплой
  через git push). Если понадобится независимость от зарубежных сервисов или вырастет
  нагрузка — можно перенести на российский VDS (Timeweb Cloud / Selectel).

## Как запустить локально

```bash
npm install
npm run dev
```

Сайт будет доступен на http://localhost:3000

## Деплой на Render

1. Зарегистрируйтесь на [render.com](https://render.com) (можно через GitHub-аккаунт).
2. Запушьте этот проект в свой репозиторий на GitHub (см. раздел «Работа через git» ниже).
3. В панели Render: **New → Web Service** → выберите репозиторий.
4. Настройки сборки:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Environment:** Node
5. Нажмите **Create Web Service** — Render соберёт и задеплоит сайт, выдаст публичный URL.
6. Дальше при каждом `git push` в основную ветку Render будет пересобирать сайт
   автоматически.

Первый запрос к сайту после периода неактивности может открываться на несколько
секунд дольше обычного — это нормальное поведение бесплатного тарифа Render,
дальше сайт работает в обычном режиме.

## Работа через git

```bash
git init
git add .
git commit -m "Этап 1: каркас проекта"
git branch -M main
git remote add origin <ссылка на ваш репозиторий на GitHub>
git push -u origin main
```

Дальше все изменения по проекту фиксируются обычными коммитами:

```bash
git add .
git commit -m "Описание изменений"
git push
```
